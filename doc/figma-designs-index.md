# Figma デザインコンテキスト一覧

このドキュメントは、Figma から取得した FloorMap デザインコンテキストのインデックスです。

## 取得済みデザイン（15個）

### 認証・アカウント管理
1. **パスワードリセット** (node-id: 2:248)
   - メールアドレス入力フォーム
   - リセットリンク送信機能

2. **パスワード再設定** (node-id: 27:4)
   - 新パスワード入力フォーム
   - パスワード確認フィールド

3. **ログイン** (node-id: 2:13)
   - メール＆パスワード認証
   - 座席配置図イラスト付きランディング

4. **サインアップ** (node-id: 2:125)
   - 新規ユーザー登録フォーム
   - パスワード強度表示

5. **2段階認証** (node-id: 2:266)
   - 6桁認証コード入力
   - タイマー表示（有効期限）

### ユーザー設定・管理
6. **プロフィール設定** (node-id: 2:965)
   - プロフィール画像編集
   - 氏名・メールアドレス変更
   - パスワード変更
   - 2FA (二要素認証) トグル
   - アカウント削除

7. **ユーザー管理** (node-id: 2:1509)
   - ユーザー一覧テーブル
   - 役割管理（システム管理者・一般ユーザー）
   - ユーザーステータス（アクティブ・停止中）
   - 2FA 有効率表示

### ルーム・座席管理
8. **ルーム一覧** (node-id: 2:296)
   - ルームカード（サムネイル付き）
   - 座席利用率プログレスバー
   - アクティブメンバーアバター表示
   - 新規ルーム作成ボタン

9. **ルーム詳細** (node-id: 2:500)
   - 座席配置図キャンバス
   - 座席ステータス一覧テーブル
   - 使用中/空き座席の判別

10. **ルーム作成** (node-id: 2:680)
    - ウィザード形式（3ステップ）
    - ルーム名・説明入力
    - サムネイル画像アップロード

11. **座席管理キャンバス** (node-id: 2:754)
    - レイアウトエディタ
    - ツールボックス（長方形・円形・テキスト・消しゴム）
    - 背景設定（グリッドスナップ・不透明度）
    - プロパティパネル（座席情報編集）

12. **メンバー権限管理** (node-id: 2:852)
    - ルーム内メンバー一覧
    - 役割管理（オーナー・管理者・編集者・メンバー）
    - メンバー招待機能

### ダッシュボード・分析
13. **分析・レポート** (node-id: 2:1203)
    - KPI カード（総座席数・利用率・平均利用時間・アクティブユーザー数）
    - グラフ表示（占有率推移・エリア別平均利用率）
    - ルーム別集計データテーブル
    - CSV エクスポート機能

14. **通知** (node-id: 2:1114)
    - 新しい通知セクション
    - 既読通知セクション
    - チェックイン・チェックアウト履歴
    - システム更新通知
    - 警告通知

### システム設定
15. **バックアップ・復元** (node-id: 2:1382)
    - バックアップ履歴テーブル
    - 復元・ダウンロード・削除アクション
    - 自動バックアップ設定
    - 実行間隔・保存期間設定

## 技術仕様

### スタイリング
- **フレームワーク:** Tailwind CSS v4
- **フォント:** Geist (Bold, SemiBold, Medium, Regular)
- **カラーシステム:** Tailwind デフォルトカラー
  - Primary: `#3b82f6` (Blue-500)
  - Success: `#10b981` (Emerald-500)
  - Error: `#ef4444` (Red-500)
  - Background: `#f8fafc` (Slate-50)
  - Text: `#0f172a` (Slate-900)

### レスポンシブ
- すべてのコンポーネントが Flexbox/Grid ベースで構築
- モバイル対応考慮済み（max-width に制限あり）

### 画像アセット
- Figma CDN から 7 日間有効なリンク付き
- asset ID 形式で参照可能

### Node ID マッピング
- `data-node-id="X:Y"` 属性で Figma との対応付け可能
- デザイン システム管理に活用できます

---

## 使用方法

1. 各デザイン コンポーネントは HTML ファイル形式で保存されています
2. React 実装時は Tailwind CSS クラスをそのまま使用可能
3. Rails Hotwire 実装時は ERB テンプレートに変換して使用
